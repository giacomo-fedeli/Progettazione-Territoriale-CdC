# analisi/ – elaborazioni fuori da Power BI (facoltative)

La traccia ammette altri strumenti purché **documentati e replicabili**.

- `code/` – teoria delle code / simulazione delle attese in PS (S1): assunzioni, parametri (arrivi, tempi di servizio, numero di serventi dal personale per turno), risultati.
- `localizzazione/` – metodo di localizzazione delle CdC (S3): clustering, centri di gravità, location-allocation…

Per ogni script indicare: input (file in `../dati/`), comando per eseguirlo, output prodotti.
I risultati che servono al confronto S4 devono tornare nel modello Power BI (es. in `../dati/scenari/`).
